# Code of Conduct

We follow the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful and constructive. Harassment, personal attacks and discrimination are not acceptable.
Maintainers may remove comments, commits or contributions that violate this, and may block repeat offenders.
Report problems to the maintainer by opening a private security advisory or emailing the address in the repository profile.
